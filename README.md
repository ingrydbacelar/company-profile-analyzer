## Sobre o projeto

O **Company Profile Analyzer** foi desenvolvido para automatizar a **análise de informações de empresas** diretamente no Google Sheets.

A solução utiliza **Google Apps Script** integrado à **API do Gemini** para processar e analisar dados empresariais, transformando informações em resultados estruturados de forma automatizada.

## Funcionalidades

* Análise automatizada de informações empresariais
* Integração com inteligência artificial
* Processamento de dados diretamente no Google Sheets
* Integração com a API do Gemini
* Organização e estruturação dos resultados
* Automação de tarefas repetitivas

## Tecnologias

* Google Sheets
* Google Apps Script
* JavaScript
* Gemini API
