## Sobre o projeto

O **Company Profile Analyzer** foi desenvolvido para **automatizar a análise e qualificação de empresas para prospecção B2B**, utilizando **Google Sheets, Google Apps Script e inteligência artificial**.

A solução integra dados da empresa e do lead, como **site, LinkedIn, setor, cargo e informações do contato**, e utiliza a **API do Gemini** para analisar o perfil da empresa, identificar o **tipo de venda mais adequado**, levantar **dores comerciais específicas** e gerar um **script de abordagem personalizado** para o lead.

O objetivo é transformar informações dispersas em **insights comerciais acionáveis**, reduzindo o trabalho manual na preparação de abordagens e tornando o processo de prospecção mais estruturado e personalizado.

## Como funciona

O processo segue um fluxo automatizado:

**Selecionar → Analisar → Identificar → Personalizar → Registrar**

1. O usuário seleciona uma empresa diretamente no Google Sheets.
2. O script coleta os dados disponíveis da empresa e do lead.
3. A IA analisa as informações fornecidas, incluindo site, LinkedIn, setor e cargo.
4. O sistema identifica o perfil e o **tipo de venda**.
5. São identificadas **3 a 5 dores comerciais específicas** da empresa.
6. A IA gera um **script de abordagem personalizado** de acordo com o contexto identificado.
7. Os resultados são registrados automaticamente em novas colunas da planilha.

## Funcionalidades

- Análise automatizada de empresas
- Integração com inteligência artificial
- Análise de informações de empresas e leads
- Identificação de perfil de compra
- Classificação entre venda consultiva e transacional
- Identificação de dores comerciais
- Geração de scripts personalizados de prospecção
- Registro automático dos resultados no Google Sheets
- Menu personalizado para execução da análise
- Configuração da API Key por meio das propriedades do script

## Tecnologias

- Google Sheets
- Google Apps Script
- JavaScript
- Gemini API

## Demonstração

O projeto foi desenvolvido para funcionar diretamente no **Google Sheets**, utilizando Google Apps Script para automatizar o processo de análise e a API do Gemini para gerar os insights comerciais.
